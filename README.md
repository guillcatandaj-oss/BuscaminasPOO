# BuscaminasPOO

# Descripción
Proyecto desarrollado para la asignatura de Programación Orientada a Objetos de la Universidad Politécnica Salesiana.

El proyecto consiste en la implementación del juego clásico Buscaminas en consola utilizando Java y aplicando principios de Programación Orientada a Objetos, arquitectura MVC y buenas prácticas de desarrollo de software.

#  Objetivos
- Aplicar conceptos de Programación Orientada a Objetos.
- Implementar la arquitectura Modelo Vista Controlador (MVC).
- Utilizar herencia, polimorfismo e interfaces.
- Manejar excepciones estándar y personalizadas.
- Implementar persistencia mediante serialización.
- Aplicar principios de código limpio.
- Desarrollar pruebas unitarias.
- Gestionar el proyecto mediante Git y GitHub.
- Características del Juego
- Tablero de 10x10 posiciones.
- Generación aleatoria de minas.
- Descubrimiento de casillas.
- Marcado de posibles minas.
- Revelado automático de casillas vacías mediante recursividad.
- Detección de victoria y derrota.
- Guardado y carga de partidas.

# Arquitectura
El proyecto sigue el patrón MVC:

# 1. Modelo
Gestiona la lógica del juego, tablero, casillas y jugador.

# 2. Vista
Muestra la información al usuario mediante consola.

# 3. Controlador
Gestiona la interacción entre la vista y el modelo.
